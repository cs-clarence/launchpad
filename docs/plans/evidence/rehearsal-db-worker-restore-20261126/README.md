# Production rehearsals: database loss, worker liveness and failed restore (2026-11-26)

Evidence for [the plan](../../production-rehearsals-db-worker-restore.md). Everything ran on one disposable
`local:deploy` stack (Docker Compose, deployments on, **aliases switched on by hand** in the project's own
`compose.env`, one worker, loopback only) at revision `8c7df7f`. Transcripts are trimmed (repeated sample lines
are cut and marked) and scrubbed: no keys, tokens, passwords, cookies or router epochs; the user's home is `~`.
`$EV` is the evidence directory of the session, `$EVROOT` its parent. Container and deployment ids are kept.

## Limits (read before relying on a verdict)

- Aliases are off in `local:deploy`; they were turned on by editing `compose.env`. One worker, a database of a
  few hundred kB (plus a 174 MB filler for V9), one migration, no real dashboard, no public ingress.
- The checkout of the first stack (`launchpad-local-3853718e`) was deleted externally during S3 (cause not
  found); that stack was removed by exact name and the rehearsal continued on `launchpad-local-27b61035`
  from a checkout under `~/.t3/worktrees`. The ledger shows both. S1, S2 and the restore pilot (S2b) were done
  on the first stack and not repeated.
- `docker kill` of a container is **not** restarted by `unless-stopped` on this host (Docker treats it as a manual
  stop), so every kill drill needed a guarded `docker start` as its undo. "The restarted worker claims" is
  simulated by that start.
- The mid-promotion hold (W6) and a `backup` killed mid-write (V4) could not be reproduced; see the verdicts.

## Deviations from the plan

- The first stack's checkout was deleted externally; the second stack replaced it (above).
- `restore` of a missing `public` needed no `--replace`; V8 used a corrupted block, not a truncation; W1 and W5
  windows changed (SQL polling, pause after `step_pending=destroy`); W6's hold was not reproduced.
- Backups were named `b0`, `b0-a`, `b0-d`, `b0-v`, `b0-v2`, `b0-v3`, `b1`.
- A few guarded `docker stop` calls followed a preceding `guard` but had no `inject` of their own; the ledger
  pairs some `INJECT` lines with the later start (or the `rekey` that restarted the service) rather than an
  identically labelled `UNDO`.
- The orphan app of D1d and the failed W7 deployment: the deployment was deleted through the API; the orphan was
  left for `down`, which removes sites by exact name.

## Teardown and proof of absence

- Before `down`: all five services healthy; the orphan app `lp-649v8kyoh8` (D1d) was left on purpose and the failed
  W7 deployment had been deleted through the API (`check-restore` was then clean, `drift` showed only the orphan).
- `local:deploy down` (62 s): stopped the controller and worker, removed 15 deployed sites (including the orphan,
  found through Dokku), the root-owned state, the project's containers, volumes, network, images and
  `.local-deploy/`, and deleted the `local-deploy` CLI profile (a later `launchpad whoami` answers "No profile named
  local-deploy"). It reported that the site image of the orphan app could not be derived; that one tag,
  `launchpad/site:a99c8fea...` (the deployment recorded in the ledger), was removed by exact name afterwards.
- After: no container, volume or network carries the project label; no `launchpad-local-*`, `launchpad/site` or
  `dokku/lp-*` image remains; `.local-deploy/` is gone. The before/after Docker snapshot (containers, volumes,
  networks and images) is **identical** to the baseline taken before the first stack was started
  (`snap-S0.txt` vs `snap-S9-after.txt`, kept only on the rehearsal host, so not verifiable from this branch).
- `cloudflare-connector` (id `6a33f7899b93...`, started 2026-11-26T01:13:31Z) and `playit-connector`
  (id `de1d2ee43a3f...`, started 2026-11-26T01:13:31Z) are unchanged from the baseline; `launchpad-test-db` did not
  exist at the baseline or afterwards.
- Pulled base images and the build cache stay, as `down` documents. The two password files in the CLI configuration
  directory also stay (they belong to accounts that no longer exist).
